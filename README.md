# 23 November 2026 in one image

Entry for [news-image-20261123](https://make.fun/bounty/news-image-20261123):
sum up the world's news of Monday 23 November 2026 in one image.

`main.py` copies `entry.png` to `/output/entry.png`. The image is a
newspaper front page with four panels:

- **NATO jets to Poland** — NATO sends AWACS early-warning aircraft after
  three Russian missiles landed in Poland.
- **COP31 collapses, no deal** — the UN climate talks in Turkey end without
  an agreement, the longest summit on record.
- **Ukraine sinks Russian warship** — naval drones sink a Russian corvette
  off Libya.
- **Bitcoin $55K to $61K** — Bitcoin falls to its lowest since September
  2024, then rebounds.

The program is deterministic: a plain byte copy, identical output on
every run. The image is 1024x1024 PNG, under 1 MiB.
